THE VERDICT THAT STARTED IT
---------------------------

    "the current state of the course logs and the courses that we
     have are not acceptable"

He arrived with four documents written outside the tree: a
High-Standard Course Creation Guide, a Rich Course Import plan, and
two finished courses — Junior Electrical Engineer, and The
Theoretical Minimum.

The reason was narrower and worse than "thin". MEASURED, first thing,
by running parseCourse() against his real frontmatter:

    ok: false

                 question or project"" — frontmatter is "key: value".' ]

THE TWO COURSES HE HAD ACTUALLY WRITTEN COULD NOT ENTER THE PAVILION
AT ALL. Three defects, and both documents hit all three:

  1. `prerequisites:` is a YAML block list. The frontmatter reader
     wanted `key: value` on every line, so it rejected each bullet
     and refused the file.
  2. Quoted values kept their quote marks — the title would have
     rendered as "Junior Electrical Engineer Path", punctuation and
     all.
  3. Everything before the first `##` was read for one paragraph and
     discarded — throwing away `# How to walk this course`, which is
     not preamble. It is the Opening Intention, required piece 1 of
     his own standard.

Four days of green round-trip tests, every one of them against
Markdown written inside the test file. Rule 1 in a new costume: the
tidy version is the one that lies. courses/ holds the real files now
and the suites read those.

"THEY'RE TITLED WRONG"
----------------------

Six books he had just brought in for the electrical course. Read
straight out of his own Postgres, they were FILENAMES:

    2018_dc-electrical-circuits-workbook
    CIRCUIT ANALYSIS  AND DESIGN 3ed
    TattersfieldGeorgeM-ElectricalCircuitAnalysis
    The_Optics_of_Ibn_Al-Haytham_Books_I

parseBookFile() falls back to file.name when an EPUB carries no title
and a .txt has no `Title:` line, which is most real downloads. The app
had written every one of them.

data/book-title.js is deterministic (rule 7) and only ever SUGGESTS
(rule 6 — a filename genuinely does not always contain the title; it
stops at the archive.org AuthorTitle identifier rather than guessing
where the name ends).

THE SWEEP IS WHAT EARNED IT. All 423 real titles, not the six: 73
would have changed and TWO OF THOSE CHANGES WERE DAMAGE —
`2011-2012` -> `2011 2012`, and `/ A Practical Handbook` -> `/ a`.
`A Guide to LaTeX` -> `La Te X` was a third, caught only by testing
titles that were already RIGHT. Now 66 suggestions, 0 unstable,
0 lossy.


A NON-BREAKING SPACE IN A REGEX
--------------------------------

The sabotage runner refused to match a line that printed as its exact
twin. U+00A0 was sitting inside `/[_ ]+/g` in code I had written an
hour earlier. Identical in an editor, in git diff, and in
JSON.stringify. Harmless here by luck — a later \s+ collapse covered
it — which is exactly why it needed a guard rather than a fix.

npm test now fails on any invisible character in src/game/. Same
family as the CRLF failure of 2026-08-13: a difference the eye cannot
resolve, silently changing what the program matches.

⚠ And the guard's own pattern is written as ESCAPES. The first
version contained the literal characters, which cannot be read,
reviewed or grepped — and would have flagged itself.

================================================================
LATER THE SAME DAY — the guided path, and the map
================================================================

    "What I really want to do is... have an idea, share with you, then
     you can help me figure out what topics to search for books and
     also how to draft a plan with ChatGPT or Grok."

THE ORDER IS THE POINT. A course drafted before you know what you are
reading names books it hopes exist; drafted after, it names the ones
on your shelf. So the draft step became three beats:

    ① your idea → ② what to read → ③ draft the course

② is HALF DETERMINISTIC AND HALF A PROMPT, and the split is rule 7.
lookupTerms() — the one term extractor in this application, shared
with the shelf lookup and passage retrieval — pulls words out of the
idea, and a substring match says which books you ALREADY OWN that
touch it. Instant, no model, no connection. Measured on a real save:
"Understand electric circuits well enough to build a motor" found
`Lessons in Electric Circuits` on the shelf.

What code CANNOT do — "what else is worth reading" — is a prompt,
told which books you own so it does not suggest them back. Its last
line asks for SEARCH TERMS RATHER THAN LINKS: a hallucinated URL
looks exactly like a real one, and a term you type yourself cannot be
a dead link.

The loop now closes:
    an idea → what to read → get the books in (titles tidied on the
    way) → draft the course → receive it → walk it → read it aloud


THE MAP
-------

ui/tree-graph.js — renderTreeGraph + graphDepths, EXTRACTED UNCHANGED
from ui/lesson-tree.js. It was already generic (needsOf / cardHTML /
onClickAttr) and its own comment already called it "the whole 'make it
look like a skill tree' ask"; the only thing between it and a second
caller was which file it lived in. The ui/dom.js precedent exactly.

⚠ THE BRANCHES ARE NOT PREREQUISITES, and that is the honest part. A
prerequisite graph matches `needs` against other node TITLES, and both
real courses list PROSE prerequisites — "Willingness to work from a
blank page". Those match no course title, so the graph would have been
one column: a list, rotated ninety degrees. The tree is built from
structure the data actually has, TRACK → COURSE → MODULE, and a
course-to-course edge is drawn only where a prerequisite genuinely
names another course on the board. Rare until somebody writes one, and
better said than shipped as an empty skill tree.

Modules draw only for the course you have opened — nine courses would
be eighty cards, the wall of text this pass removed, rebuilt in SVG.
Measured: 4 nodes / 2 edges collapsed, 13 / 11 with one expanded.

Read the picture, and it reads: tracks left, courses centre, modules
branching right. Known rough edge: a long title truncates at the fixed
196px card ("The Theoretical Minimum — Historical Gate + Modern C").
Honest truncation, not breakage, and left as-is rather than gold-plated.
