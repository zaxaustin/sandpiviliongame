# plans/done — plans that are fully built and closed

These are kept for the record, not because anything's still open in them.
A plan lands here once its work is genuinely done and verified — the same
`done/` convention `library-drafts/done/` already uses. The active
`plans/` folder above stays a list of what's actually still open, so a
fresh session scanning "what's next" isn't wading through finished work.

Nothing here needs re-reading to know the current state — that's what
`README.md` is for. These are the receipts.
